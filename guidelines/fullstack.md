## Stack & tooling
- Use `pnpm` by default for new projects
- If not already established in the codebase, pick `PostgreSQL`, `FastAPI`, `Tanstack` and `Shadcn`

## Conventions
Use conventions established in the codebase. If none present or starting from scratch, 
follow the [Full Stack FastAPI Template](https://github.com/fastapi/full-stack-fastapi-template)
